# T7 results: policy-as-code

## Built
- `policy/`: `global.yaml` (tier ladder, capability -> tier), `teams/`, `agents/` (mirrors `deploy/agents.json`: hr, finance-recon, coding), `trust/<key_id>.pub.json` (committed public key), `CODEOWNERS`, `schema.json`.
- `services/policy/govpolicy/` (installable, `policyctl` entry point, importable by the control plane):
  `schema.py` (pydantic, strict, cross-checks; queries `model_allowed`, `max_tokens_ceiling`, `requires_approval`, `required_tier`),
  `signing.py` (`Signer`/`Verifier` ABCs, Ed25519 implementation, `module:factory` plugin hook for cosign/HSM),
  `bundle.py` (canonical payload + detached-in-file signature, content hash, git commit, effective version `v<seq>-<hash12>`),
  `store.py` (versioned bundles, active pointer, append-only `history.jsonl`, `load_active`, `activate`, `rollback`),
  `admission.py` (`admit()`), `cli.py`.
- Private key: `.local/policy/signing.key` (gitignored). Store: `.local/policy/store`.
- `docs/policy/README.md`: PR-review approval flow.

## Behaviour verified
- Unsigned, tampered, wrong-key, forged-key-id, empty-trust-store and malformed bundles are rejected; signature is checked before the payload is parsed; loader fails closed (no active bundle, tampered stored bundle, bad activation target keeps the previous active version).
- Admission: `executes_model_code` at `container`/`gvisor` denied (needs `microvm`); omitting declared capabilities does not lower the bar; undeclared/unknown capability, unknown agent, disallowed image, unknown tier all denied with reasons. CLI exit codes 0/1/2.
- Rollback restores the previous signed bundle, refuses a tampered target, history keeps every version.
- Live check against the real key/policy: `admit coding-agent ... --tier gvisor` -> DENY (exit 1); `--tier microvm` -> ADMIT; `drift` vs `deploy/agents.json` clean.

## Simplifications
- Admission is a function/CLI, not a webhook: nothing yet calls it at container start (T3/T4 or a compose wrapper should invoke it). Sandbox tiers are labels, not real gVisor/microVM runtimes.
- Signing key is an unencrypted PEM on disk; no key expiry/revocation list (rotation = edit `policy/trust/`).
- Store is local files with no locking (single operator); `history.jsonl` is append-only by convention, not tamper-evident (bundles themselves are signed).
- Rollback to an older signed bundle is allowed by design (no anti-downgrade counter).
- Git approval is by convention plus CODEOWNERS (placeholder `@org/...` handles); nothing verifies that a bundle was built from a reviewed commit beyond recording `git_commit`/`git_dirty`.
- The gateway budget hook and control plane do not consume policy yet; `policyctl drift` only reports differences from `deploy/agents.json`.
